---
description: Cómo ejecutar el servidor local del Wall Panel
---

Para ejecutar el servidor local y habilitar el control de dispositivos Tuya e SmartThings, sigue estos pasos:

1. Abre una terminal o consola de comandos (PowerShell o CMD) en la carpeta del proyecto.
2. Asegúrate de tener las dependencias instaladas con:
```powershell
npm install
```
3. Ejecuta el servidor con el comando:
```powershell
npm start
```

El servidor estará escuchando en el puerto 3000 por defecto (o el configurado en tu `.env`).
